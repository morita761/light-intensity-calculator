# TensorBoard で学習曲線を表示する

## 使い方
```
tensorboard --logdir .\output\
```

### 最も重要なグラフ
## total_loss (または loss/total_loss)
意味: モデル全体の損失関数（誤差）の値を表します。この値が低いほど、モデルが訓練データに対して正しく予測できていることを示します。  
見るべき点:  
- 徐々に減少しているか？: 学習が順調に進んでいれば、イテレーション（またはエポック）が進むにつれて total_loss は減少していくはずです。
- 収束しているか？: ある程度イテレーションが進むと、損失の値は横ばいになり、それ以上大きく減少しなくなります。これが収束の兆候です。
- 振動（スパイク）: 大きな振動がある場合、学習率が高すぎるか、バッチサイズが小さすぎる可能性があります。

## loss/cls_loss (分類損失)
意味: 物体が何であるかを正しく分類できているかを示す損失です。  
見るべき点: total_loss と同様に減少していくか確認します。  
## loss/box_reg_loss (バウンディングボックス回帰損失)
意味: 物体の位置とサイズを正しく予測できているかを示す損失です。  
見るべき点: total_loss と同様に減少していくか確認します。
## loss/mask_loss (マスク損失)
意味: インスタンスセグメンテーション（ピクセルレベルのマスク）を正しく予測できているかを示す損失です。馬蹄形の輪郭の精度に直結します。  
見るべき点: total_loss と同様に減少していくか確認します。
