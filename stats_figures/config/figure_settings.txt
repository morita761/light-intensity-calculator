# ==========================================================================
# 図の設定（タイトル・軸ラベル・軸範囲・サイズ・色など）
#
# [セクション名] = スクリプト名。[common] は全スクリプト共通の既定値で、
# 各セクションに同じキーを書くと上書きされる。
#
# 書式:
#   文字列     title = Intensity            （\n で改行）
#   数値       title_fontsize = 14
#   組         figsize = 10, 7               （幅, 高さ インチ）
#   軸範囲     ylim = 0, 100   /   ylim = auto（データに合わせて自動）
#   リスト     branch_labels = Ventral branch, Dorsal branch
#   キーを空にする（title = ）と、その文字は表示しない
#
# 複数パネルの図では「接頭辞_キー」で個別に指定できる
#   （例: ventral_title, dorsal_title）。接頭辞付きがなければ接頭辞なしのキーを使う。
#
# 文字無し版は --no-text / --both で出力（ここの設定は変えなくてよい）
# ==========================================================================
