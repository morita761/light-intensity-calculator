# ==========================================================================
# 画像セットの定義（heatmap/ の全スクリプト共通）
#
# [セット名] が --set / --groups で指定する名前になる。
#   label  : グラフに表示する名前
#   dir    : image_root からのフォルダ
#   images : 1行に1組。列は「 | 」で区切る
#       元画像.png                         ← マスクは「元画像名(拡張子なし) + mask_suffix」
#       元画像.png | マスク.tif
#       元画像.png | マスク.tif | RFP画像.png | RFPマスク.tif    ← モザイク解析用（mosaic_compare.py）
#   行頭に # を付けるとその行は使わない
#
# 画像は heatmap/pics/ に置く（git管理外）。
# ==========================================================================
